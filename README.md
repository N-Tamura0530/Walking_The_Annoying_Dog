## 概要

デスクトップ上を知る人ぞ知るあの犬が自動で歩き回るだけのアプリです。  
それ以外の機能はありません。  
それ以外の機能は、本当にありません。

---

## 動作環境

- Python 3.x
- PyQt5

## インストール

```bash
pip install PyQt5
```

## 起動方法

```bash
python main.py
```

`Annoying Dog.png`（スプライトシート）が `main.py` と同じディレクトリに必要です。

---

## 機能

| 機能 | 説明 |
|------|------|
| 自動移動 | キャラクターが画面内を30ms間隔で自動的に動き回る |
| 反射 | 画面端に当たると反射して折り返す |
| 方向別アニメーション | 左右の向きに応じてアニメーションフレームが切り替わる |
| 休止モード | 30〜60秒ごとにランダムで立ち止まり、休憩アニメーションを再生する |
| ドラッグ移動 | 左クリックでキャラクターをドラッグして任意の位置に移動できる |
| 終了 | 右クリックで終了確認ダイアログが表示される |
| 画面外補正 | キャラクターがプライマリスクリーン外に完全に出た場合、初期位置（100, 100）に戻る |

---

## 操作方法

- **左クリック＋ドラッグ** : キャラクターを好きな場所に移動できます（放すと自動移動を再開します）
- **右クリック** : 終了確認ダイアログが表示されます
